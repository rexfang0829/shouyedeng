# 守夜燈

**立即遊玩：https://rexfang0829.github.io/shouyedeng/**

朋友打開同一個網址、輸入同一個房號就能一起玩，不需要登入。

即時合作生存射擊。玩家操控燈靈自動射擊，一起守護中央篝火，撐過越多波越好。

- 核心：走位＋自動射擊＋升級三選一（多重彈、連鎖閃電、環繞火球、寒霜…）
- 合作：共享篝火與全隊等級，倒地的隊友要站到身邊才能救起
- 留存：每局 5–10 分鐘不限次數；燈芯換永久強化；守夜紀錄排行榜
- 多人同步：claude.ai Artifact 的 `room` 能力，房號最小的在線玩家當主機模擬，每 100ms 廣播快照；主機離開時由下一位從最後快照接手
- 一般網址（GitHub Pages）使用 Supabase Realtime 連線，排行榜存在 Supabase `records` 資料表
- 單一 `index.html`，無建置步驟
